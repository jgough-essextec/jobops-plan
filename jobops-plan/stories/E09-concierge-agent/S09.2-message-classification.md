## User story

As the Concierge, I want each new message classified so that only job-relevant mail gets attention.

## Context

Two stages — deterministic pre-filter (known ATS sender domains like greenhouse/lever/workday, recruiter keywords, thread already linked) then LLM classification into: interview_request, recruiter_outreach, rejection, assessment, offer, info_request, application_ack, not_job_related. Output includes confidence; low confidence → 'needs_doc_look'.

## Acceptance criteria

- [ ] ≥ 90% accuracy on labeled mailbox fixture
- [ ] Phishing/suspicious messages flagged, never acted on
