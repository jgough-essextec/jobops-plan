## User story

As the Concierge, I want each relevant message tied to the right application so that the ledger and Doc see responses in context.

## Context

Signals — thread already linked; sender domain ↔ company domain; company name and role title in subject/body (fuzzy); ATS job id in links; recency of APPLIED. Score and pick best; ambiguous (top-2 within margin) → needs_doc_look with candidates. Unmatched recruiter outreach creates a new lead (DISCOVERED, source=inbound).

## Acceptance criteria

- [ ] ≥ 95% correct match on fixture set
- [ ] Ambiguous matches never auto-linked
