## User story

As the Ledger, I want inbox events to move applications forward so that state reflects reality.

## Context

Mapping — interview_request → INTERVIEWING; rejection → REJECTED; offer → OFFER; recruiter_outreach/info_request on an applied job → RESPONDED. Only for jobs in APPLIED or later. Each transition references the inbox event id.

## Acceptance criteria

- [ ] Transitions only from legal states; otherwise event recorded without transition
