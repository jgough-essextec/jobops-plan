## User story

As Doc, I want my inbox content handled minimally and safely so that private mail isn't stored needlessly and hostile emails can't steer the agents.

## Context

Only job-related messages are persisted (body excerpt ≤ 2k chars, headers needed for matching); others store message id + category only. Logs redact emails/phones. Email content passed to models inside clearly delimited data blocks with an instruction hierarchy; Concierge toolset is MCP-only with no network/web; links never fetched automatically.

## Acceptance criteria

- [ ] not_job_related messages leave no body in DB or logs
- [ ] Injection eval set — 0 tool calls outside allowed set
