## User story

As Doc, I want the safety guarantees proven by tests on every change so that JobOps never submits, sends, fabricates or exceeds its scope.

## Context

Collect every [guardrail] test into a dedicated suite and add structural checks — static scan for forbidden capabilities (send email, HTTP POST to job boards' apply endpoints, gmail.send scope), toolset/allow-list matrix assertions, provenance cannot be bypassed, APPLIED only by doc. Required status check on main.

## Acceptance criteria

- [ ] Suite runs in CI as a required check
- [ ] A seeded violation in a throwaway branch makes the gate fail
