## User story

As Doc, I want to trace any artifact or decision back to its inputs, model and prompt so that I can trust and debug the system.

## Context

Every ledger event and artifact version carries — actor, Paperclip run id, model id, prompt template hash, skill versions, input hashes (JD, master CV). `jobops trace <job_id>` prints the full timeline with links to Paperclip run transcripts.

## Acceptance criteria

- [ ] Trace complete for 100% of jobs in E2E suite
