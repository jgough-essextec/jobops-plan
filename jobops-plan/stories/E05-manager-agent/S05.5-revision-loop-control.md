## User story

As the Manager, I want Critic feedback routed back to the Tailor with a cap so that artifacts improve without infinite loops.

## Context

On REVISE: Manager creates a [REVISE] child issue for Tailor containing the Critic's findings (structured), attempt=n. After 2 REVISE cycles the state machine escalates (S01.2); Manager notifies Doc with both versions and the open findings. Doc 'revise' from Telegram also creates a [REVISE] issue with Doc's comments.

## Acceptance criteria

- [ ] Findings passed verbatim as structured data in the issue
- [ ] Attempt counter consistent between issue and ledger
