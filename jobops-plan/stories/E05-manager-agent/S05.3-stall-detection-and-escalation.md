## User story

As Doc, I want stuck work noticed and escalated so that the pipeline never silently stops.

## Context

SLA per state (e.g., TAILORING 6h, IN_REVIEW 4h, failed run ×2). Manager retries once by re-assigning; on second breach transitions to ESCALATED and notifies Doc with the last run transcript link.

## Acceptance criteria

- [ ] Escalation happens within one heartbeat after SLA breach
- [ ] Retries capped at 1 per stage
