## User story

As Doc, I want jobs routed by fit tier so that effort goes to the best matches and I decide the borderline ones.

## Context

Policy (config): A/B → SHORTLISTED (auto) → Tailor. C → HOLD, listed in digest for Doc to promote. D/F → ARCHIVED with reason. Overrides: company on Doc's watchlist always ≥ HOLD; red flags (e.g., 'unpaid', 'commission-only') → ARCHIVED. Daily cap on new SHORTLISTED (default 5) to limit spend.

## Acceptance criteria

- [ ] Routing decisions logged with rule id
- [ ] Daily cap respected; overflow queued by score
