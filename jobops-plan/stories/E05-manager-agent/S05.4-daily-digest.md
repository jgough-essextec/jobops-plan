## User story

As Doc, I want one daily digest on my phone so that I see the pipeline without notification fatigue.

## Context

Digest: new roles (by tier), HOLD items to decide, READY_FOR_DOC count, inbox items needing a decision, escalations, spend vs budget, screened-out counts by reason. Delivered at 07:30 local via Telegram (summary + deep links) and as a Notion page.

## Acceptance criteria

- [ ] Digest content generated from ledger by a deterministic builder (LLM only for optional 2-line summary)
- [ ] Empty sections omitted
