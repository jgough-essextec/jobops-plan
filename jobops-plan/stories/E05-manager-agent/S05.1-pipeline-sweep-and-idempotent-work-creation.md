## User story

As the Manager, I want each heartbeat to sweep the ledger and create exactly one issue per piece of pending work, assigned to the right agent, so that nothing is missed or done twice.

## Context

Sweep: list jobs by actionable state (DISCOVERED→Scout evaluate; SHORTLISTED→Tailor; DRAFTED/REVISED→Critic; inbox events needing briefs→Concierge). Before creating, search open issues by job_id + stage; reuse if found. Uses Paperclip checkout so two Manager runs can't race. Implemented as a Manager skill + a deterministic `manager.plan_sweep` helper tool so the routing logic is unit-testable.

## Acceptance criteria

- [ ] 10 consecutive heartbeats on a static ledger create issues only on the first
- [ ] Every created issue carries job_id front-matter and correct assignee
