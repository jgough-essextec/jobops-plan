## User story

As Doc, I want career-ops' own tracker kept consistent with the ledger so that career-ops dashboards and tools still work without becoming a second truth.

## Context

Ledger wins. A one-way projection writes tracker rows from ledger state (using career-ops' status vocabulary via a mapping); a read-back detects manual edits and raises a reconciliation item for Doc instead of silently overwriting.

## Acceptance criteria

- [ ] Status mapping covers every ledger state
- [ ] Manual tracker edits surface as reconciliation items
