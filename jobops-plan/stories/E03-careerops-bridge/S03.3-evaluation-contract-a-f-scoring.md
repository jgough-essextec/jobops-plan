## User story

As the Scout, I want to evaluate a job with career-ops' evaluation logic and get back a validated, structured report so that the Manager can route on it.

## Context

Per ADR-3 the Scout's Hermes session loads career-ops' evaluation mode as a skill and reasons over JD + profile. It submits via careerops.submit_evaluation(job_id, report), which validates against evaluation.schema.json (grade A–F, score 1–5, per-dimension scores, rationale, red flags, comp estimate) and attaches to the ledger. careerops.get_evaluation_context(job_id) returns JD + profile excerpt + mode prompt version.

## Acceptance criteria

- [ ] Invalid reports rejected with schema path errors so the agent can retry
- [ ] Report records mode prompt version and model id
- [ ] Evaluation attached and job transitioned to EVALUATED atomically
