## User story

As the builder, I want career-ops pinned as a submodule with a health check so that upgrades are deliberate and breakage is caught immediately.

## Context

vendor/career-ops at the SHA from S00.2. Bridge exposes health() wrapping `npm run doctor`. An upgrade script bumps the SHA and runs the career-ops contract suite.

## Acceptance criteria

- [ ] Bridge health reports doctor result and SHA
- [ ] `make upgrade-careerops SHA=…` fails if any contract test fails
