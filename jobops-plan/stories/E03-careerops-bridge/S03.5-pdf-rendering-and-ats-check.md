## User story

As Doc, I want each approved-for-review CV rendered to PDF with career-ops' template and verified as machine-readable so that ATS parsers read it correctly.

## Context

careerops.render_pdf(artifact_version_id) calls career-ops' Playwright PDF script. ATS check extracts text (pdfminer) and verifies section order, contact info, no text-in-images, page count limit.

## Acceptance criteria

- [ ] PDF stored with hash and linked to the artifact version
- [ ] ATS check results stored; failing PDFs flagged for Critic
