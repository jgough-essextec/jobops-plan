## User story

As the Scout, Tailor and Critic, I want career-ops capabilities as one MCP server with per-agent permissions so that each agent sees only what it needs.

## Context

Allow-lists: Scout(evaluate.*, scan), Tailor(profile.*, tailor.*, render_pdf), Critic(artifacts.read, profile.get_summary), Manager(health, tracker.reconcile).

## Acceptance criteria
