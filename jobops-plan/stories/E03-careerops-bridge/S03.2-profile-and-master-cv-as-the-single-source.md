## User story

As Doc, I want one master CV and profile that every artifact derives from so that nothing is invented and updates propagate.

## Context

Master CV (markdown) + config/profile.yml live in a private `profile/` directory mounted into the bridge (not in repo). Bridge validates structure, computes a content hash, and parses the CV into a claim inventory (roles, dates, achievements, metrics, skills, publications) used for provenance checks (S03.4).

## Acceptance criteria

- [ ] Validation errors are line-referenced
- [ ] Claim inventory extracted with stable IDs
- [ ] Master CV hash recorded on every artifact version
