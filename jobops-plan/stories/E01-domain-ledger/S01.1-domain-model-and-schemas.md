## User story

As every agent and service, I want one typed domain model so that data passed between tools is validated in one place.

## Context

Pydantic v2 models: Job, Company, SearchProfile, Evaluation, ArtifactSet, ArtifactVersion, Review, Finding, InboxEvent, DecisionBrief, Actor. Export JSON Schema for TS consumers and MCP tool definitions. Shapes informed by S00.2/S00.4 fixtures.

## Acceptance criteria

- [ ] All models round-trip JSON without loss
- [ ] JSON Schemas generated into schemas/ and checked in; CI fails if stale
- [ ] Fixture records from S00.2/S00.4 parse into the models
