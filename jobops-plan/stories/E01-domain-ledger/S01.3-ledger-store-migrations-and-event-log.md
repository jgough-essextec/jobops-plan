## User story

As the system, I want job state persisted with an append-only event log so that state is durable, auditable and rebuildable.

## Context

SQLite (WAL) via SQLAlchemy + Alembic. Tables: jobs, evaluations, artifact_sets, artifact_versions, reviews, inbox_events, events (append-only). Idempotent upsert keyed by job fingerprint. Optimistic concurrency via version column.

## Acceptance criteria

- [ ] Every transition writes exactly one event row in the same DB transaction
- [ ] Replay of events reproduces current job state exactly
- [ ] Concurrent writers on same job → one wins, the other gets ConcurrencyError
