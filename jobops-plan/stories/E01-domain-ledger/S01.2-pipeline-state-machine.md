## User story

As the Manager, I want a guarded state machine for jobs so that agents can only move work forward along legal paths and every move is attributable.

## Context

States and transitions from PLAN §4. Guards: actor permissions per transition (e.g. only `doc` → APPLIED; only Critic → READY_FOR_DOC; revision count ≤ 2 for REVISE). Pure logic, no IO.

## Acceptance criteria

- [ ] Transition table is data (YAML) and the diagram in PLAN §4 is generated from it
- [ ] Illegal transitions raise IllegalTransition with from/to/actor
- [ ] Actor guards enforced; revision cap enforced
