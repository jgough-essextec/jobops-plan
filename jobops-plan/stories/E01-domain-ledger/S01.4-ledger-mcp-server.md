## User story

As a Hermes agent, I want ledger operations as MCP tools so that I can read and move jobs without database access.

## Context

Tools: ledger.get_job, ledger.list_by_state, ledger.transition (actor taken from the authenticated agent key, never from args), ledger.attach_evaluation, ledger.attach_artifact_version, ledger.attach_review, ledger.record_inbox_event. Per-agent tool allow-lists enforced server-side.

## Acceptance criteria

- [ ] Tool schemas derived from domain JSON Schemas
- [ ] Actor identity comes from the MCP connection credential
- [ ] Agent calling a tool outside its allow-list gets a permission error
