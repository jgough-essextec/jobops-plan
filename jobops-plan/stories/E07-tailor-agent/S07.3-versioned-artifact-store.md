## User story

As Doc, I want every artifact version kept with its inputs so that I can compare versions and know exactly what produced each one.

## Context

Content-addressed store on disk (sha256), metadata in ledger (job_id, version, parent_version, model, prompt hash, skill version, master CV hash, created_by). Diff view (markdown) between versions. Links usable from Notion/Telegram.

## Acceptance criteria

- [ ] Identical content dedups to the same blob
- [ ] Version lineage queryable
