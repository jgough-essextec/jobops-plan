## User story

As the Tailor, I want to produce a tailored CV, cover letter and PDF for each shortlisted job so that Doc gets an application-ready package.

## Context

[TAILOR] issue → tailor.get_context (JD, evaluation, master CV, claim inventory, company notes) → generate with career-ops tailoring skill → tailor.submit (provenance-checked) → render_pdf → ledger DRAFTED → issue closed. On provenance rejection, self-correct up to 2 times.

## Acceptance criteria

- [ ] Artifact set = CV (md + pdf), cover letter (md), claim_map, keywords covered
- [ ] Provenance rejection loop bounded
