## User story

As the builder, I want a live eval suite for tailoring quality so that changes in models or prompts are measured.

## Context

20 synthetic job/profile pairs. Metrics — provenance violations (must be 0 after self-correction), keyword coverage, length limits (CV ≤ 2 pages, cover letter ≤ 350 words), company/role name correctness, judge-rated relevance (Critic model, blind).

## Acceptance criteria

- [ ] Zero provenance violations in final outputs
- [ ] Coverage and length targets met for ≥ 90% of cases
