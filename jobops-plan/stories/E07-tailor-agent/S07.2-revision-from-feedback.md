## User story

As the Tailor, I want to revise an artifact set using structured findings so that every must-fix item is addressed and I can show what changed.

## Context

[REVISE] issue includes findings (id, severity, location, suggestion). Tailor produces a new version plus a changelog mapping finding id → change or 'declined: reason'. Must-fix cannot be declined.

## Acceptance criteria

- [ ] Changelog covers every finding
- [ ] Must-fix declined → submission rejected
