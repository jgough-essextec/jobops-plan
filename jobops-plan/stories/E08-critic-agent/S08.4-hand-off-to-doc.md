## User story

As Doc, I want a ready package delivered to my phone with everything I need to decide so that I can approve, revise or skip in under a minute.

## Context

On READY_FOR_DOC — create a Paperclip approval request (type artifact_review) linked to the job issue; Telegram card with role, company, grade, 3-line why, Critic's nits, links to PDF and cover letter, buttons Approve / Revise / Skip; Notion row moves to 'Ready for Doc'.

## Acceptance criteria

- [ ] One approval request per artifact version
- [ ] Card renders within Telegram limits; links work over Tailscale
