## User story

As the Critic, I want cheap deterministic checks to run before any model review so that obvious defects are caught for free and with certainty.

## Context

review-checks service — company and role name match JD exactly; no other company names in the cover letter; dates consistent; contact info present and matching profile; PDF ATS check results; banned phrases list; length/page limits; spelling (en-US dictionary + custom terms list).

## Acceptance criteria

- [ ] Each check returns typed findings mapped to rubric dimensions
- [ ] Runs in < 2s per artifact set
