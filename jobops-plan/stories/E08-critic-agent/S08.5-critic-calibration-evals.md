## User story

As the builder, I want to measure how well the Critic catches real defects without nitpicking good work so that its gate is trustworthy.

## Context

Calibration set of 40 artifact sets — 25 seeded with known defects (one or more per rubric dimension), 15 clean. Metrics — catch rate per dimension, false-positive rate on clean set, verdict accuracy.

## Acceptance criteria

- [ ] Catch rate ≥ 90% overall, 100% on fidelity
- [ ] False-positive must-fix rate on clean set ≤ 15%
