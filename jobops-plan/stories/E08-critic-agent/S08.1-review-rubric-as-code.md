## User story

As the Critic, I want an explicit, versioned rubric so that my reviews are consistent and Doc knows what was checked.

## Context

Rubric dimensions — factual fidelity (vs master CV), JD alignment (must-haves addressed), company/role correctness, ATS readiness, clarity/tone, concision/length, typos/grammar, cover-letter specificity (not generic). Each has checks, severity (must-fix/should-fix/nit) and pass threshold. Stored as rubric.yaml; rendered into the Critic skill.

## Acceptance criteria

- [ ] Verdict rules — any must-fix → REVISE; fidelity violation → BLOCK; else PASS
- [ ] Rubric version recorded on each review
