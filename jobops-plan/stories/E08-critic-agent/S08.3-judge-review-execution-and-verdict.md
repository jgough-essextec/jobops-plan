## User story

As the Critic, I want to review each artifact set with an independent model against the rubric and record a structured verdict so that only good work reaches Doc.

## Context

[REVIEW] issue → review.precheck → artifacts.read + profile.get_summary + JD → judge reasoning with rubric skill on Claude Opus or Gemini (≠ Tailor model, enforced by config check) → review.submit(verdict, findings[]) → ledger READY_FOR_DOC / REVISE / BLOCKED.

## Acceptance criteria

- [ ] Review stores model id, rubric version, prechecks and findings
- [ ] Config check fails if Critic model family == Tailor model family
