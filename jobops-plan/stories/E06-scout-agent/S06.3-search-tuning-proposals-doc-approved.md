## User story

As Doc, I want the Scout to propose changes to my search profiles based on what I accept and reject so that searches get sharper without changing behind my back.

## Context

Weekly, Scout analyzes Doc's promote/skip decisions and evaluation outcomes and proposes a diff to search_profiles.yaml/portals.yaml as a Paperclip approval request. Only on approval does a tool apply the diff (commit to config repo).

## Acceptance criteria

- [ ] Proposals are diffs with rationale and evidence counts
- [ ] No profile change without an approved approval id
