## User story

As the Scout, I want to run all enabled search profiles and portal scans on schedule so that new roles land in the ledger twice a day.

## Context

Scout heartbeat (no task) → run search.run for each enabled profile and careerops.scan for portals.yaml; post a run summary comment to the Discovery project issue; Manager's next sweep picks up DISCOVERED.

## Acceptance criteria

- [ ] Summary comment lists per-profile counts and site failures
- [ ] Re-running within the same bucket does not duplicate (idempotent)
