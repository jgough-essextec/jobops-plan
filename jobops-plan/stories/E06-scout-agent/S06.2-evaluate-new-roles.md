## User story

As the Scout, I want to evaluate each job the Manager assigns me with career-ops' A–F logic so that the Manager can route on fit.

## Context

[EVALUATE] issue → Scout fetches evaluate.get_context, reasons with the career-ops evaluation skill, submits; on validation error retries up to 2 times with the errors; on success closes the issue with grade + one-line rationale. Batch mode: up to N evaluations per run.

## Acceptance criteria

- [ ] Validation errors trigger self-correction, max 2 retries, then the issue is marked failed for Manager
- [ ] Evaluation includes model id and skill version
