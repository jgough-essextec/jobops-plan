## User story

As the builder, I want a live-model eval suite for the Scout so that model or prompt changes don't silently degrade scoring.

## Context

Golden set of 40 synthetic JDs with Doc-labeled expected tier. Metrics — tier agreement, score consistency across 3 runs, red-flag recall, injection resistance. Runs nightly and before any model/prompt change merges.

## Acceptance criteria

- [ ] Tier agreement ≥ 80% (exact) and ≥ 95% (±1 tier)
- [ ] Score std-dev ≤ 0.5 across 3 runs per JD
