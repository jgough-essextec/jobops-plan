## User story

As the builder, I want recorded JobSpy outputs per site and observed failure modes so that normalization and resilience are tested against real data.

## Context

`scrape_jobs(site_name, search_term, google_search_term, location, distance, job_type, results_wanted, hours_old, country_indeed, linkedin_fetch_description, description_format, proxies)` returns a DataFrame. Endpoints cap around 1000 results; 429 on aggressive use.

## Acceptance criteria

- [ ] Parquet fixtures for each enabled site (indeed, linkedin, google, zip_recruiter, glassdoor) for 2 search terms
- [ ] Column inventory with null rates per site
- [ ] Observed failure modes documented (429, empty results, partial descriptions) with reproduction notes
