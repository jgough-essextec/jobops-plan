## User story

As Doc, I want the whole stack to start with one command on the Spark and be reachable over Tailscale so that I can run and manage it from my phone.

## Context

docker compose: paperclip, litellm, ledger, jobspy_svc, careerops_bridge, inbox, notion_sync, telegram_bot. LiteLLM routes: nemotron (local vLLM), claude-opus, gemini, plus a `mock/*` route returning scripted completions for tests. Secrets via sops-encrypted .env.

## Acceptance criteria

- [ ] `make up` brings all containers healthy; `make down` cleans up
- [ ] LiteLLM has per-agent virtual keys and a mock route
- [ ] Paperclip UI reachable only via Tailscale hostname
