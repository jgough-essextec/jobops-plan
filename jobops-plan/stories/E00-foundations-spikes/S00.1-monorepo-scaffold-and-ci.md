## User story

As the builder, I want a monorepo with Python and TypeScript toolchains and CI so that every later story starts from a red-green-refactor loop that is enforced automatically.

## Context

Python (uv, pytest, hypothesis, ruff, mypy) for services; TypeScript (pnpm, vitest, tsc) for Paperclip-side tooling and the Telegram bot. GitHub Actions. Make targets wrap everything so agents and humans run the same commands.

## Acceptance criteria

- [ ] `make test` runs unit + contract suites for both languages
- [ ] CI fails a PR if coverage of changed lines < 90% or lint/type-check fails
- [ ] A PR template contains the Task DoD and Story DoD checklists from PLAN §6
