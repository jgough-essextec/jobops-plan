## User story

As each agent, I want a role-specific prompt template and skills so that every heartbeat starts with my mission, my tools and my rules.

## Context

prompts/<agent>.hbs use hermes_local variables ({{agentName}}, {{taskId}}, {{taskTitle}}, {{taskBody}}, {{wakeReason}}, {{commentId}}, {{#noTask}}…). Skills: paperclip/skills/* (SKILL.md: ledger tools, careerops modes, review rubric, inbox handling, issue conventions, safety rules). Synced via adapter listSkills/syncSkills.

## Acceptance criteria

- [ ] Template renders for every wake reason without missing variables
- [ ] Each agent's enabled skill set matches company.yaml
- [ ] Safety rules skill is enabled for every agent and cannot be toggled off by apply
