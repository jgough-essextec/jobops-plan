## User story

As the Manager and each specialist, I want a standard issue format linked to ledger jobs so that every unit of work is traceable and machine-parseable.

## Context

Issue title `[<STAGE>] <Company> — <Role>`; body starts with YAML front-matter (job_id, stage, ledger_version, parent_issue, attempt) then human-readable context. Labels: stage:*, tier:*, agent:*. Library (TS + Python) to create, parse and update.

## Acceptance criteria

- [ ] Round-trip create → parse returns the same metadata
- [ ] Malformed front-matter detected and reported to Manager
