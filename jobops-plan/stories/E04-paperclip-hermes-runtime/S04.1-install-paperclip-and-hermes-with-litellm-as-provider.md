## User story

As Doc, I want Paperclip and Hermes running on the Spark with all model traffic going through LiteLLM so that models are swappable and spend is attributable.

## Context

Paperclip container at pinned version. Hermes installed in the same container (hermes_local requires same machine), ~/.hermes/config.yaml pointing at LiteLLM's OpenAI-compatible endpoint. MCP servers registered in Hermes config per agent profile.

## Acceptance criteria

- [ ] `hermes chat -q 'ping'` inside the container returns via LiteLLM
- [ ] Paperclip health + adapter testEnvironment pass
