## User story

As the builder, I want a scriptable fake Hermes CLI so that Paperclip orchestration and agent tool-call sequences can be tested deterministically without any LLM.

## Context

fakes/fake-hermes: accepts the same CLI args as `hermes chat -q`, reads a scenario file (keyed by agent + wake reason + task label) that lists MCP tool calls to make and the final message to print. It actually calls the MCP servers, so component tests see real side effects. Supports --resume to assert session continuity.

## Acceptance criteria

- [ ] Paperclip runs fake-hermes via hermesCommand; runs appear in UI with transcripts
- [ ] Scenarios can assert expected tool results and fail the run on mismatch
