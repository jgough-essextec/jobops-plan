## User story

As Doc, I want each agent to have a budget, a schedule and only the tools it needs so that cost and blast radius are bounded.

## Context

Paperclip budgets per agent (soft warning at 80%, hard stop at 100%). Heartbeats: Manager 2h, Scout 12h, Concierge 30m, Tailor/Critic on-assignment only. Hermes toolsets restricted (e.g. no terminal/browser for Critic/Concierge; MCP only). LiteLLM per-key max budget as a second limit.

## Acceptance criteria

- [ ] Budget exhaustion pauses the agent and notifies Doc
- [ ] Toolsets per agent verified by test
