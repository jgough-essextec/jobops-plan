## User story

As Doc, I want the JobOps company, agents, reporting lines and settings declared in YAML and applied idempotently so that the setup is reproducible and reviewable.

## Context

paperclip/company.yaml: company (name, mission, goals), projects (Discovery, Applications, Inbox), agents (name, role, reportsTo, adapterType hermes_local, adapterConfig: model, toolsets, timeoutSec, persistSession, promptTemplate ref, env incl. per-agent LiteLLM key + MCP creds), budgets, heartbeat schedules. `jobops company apply|diff`.

## Acceptance criteria

- [ ] apply on empty Paperclip creates everything; second apply is a no-op
- [ ] diff shows UI-made changes as drift
- [ ] Secrets referenced, never inlined
