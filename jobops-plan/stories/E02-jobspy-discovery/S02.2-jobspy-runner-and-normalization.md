## User story

As the Scout, I want each profile run turned into normalized Job records so that downstream steps never deal with per-site quirks.

## Context

Map DataFrame columns to Job: title, company, company_url, location (city/state/country/remote), job_type, salary (interval → annualized min/max/currency), date_posted, job_url (canonicalized), job_url_direct, description (markdown), site, raw (JSON). JobSpy is called behind an interface so tests use fixture replay.

## Acceptance criteria

- [ ] Every fixture row normalizes or is rejected with a reason
- [ ] Hourly/monthly salaries annualized with recorded assumption (2080h, 12mo)
- [ ] Tracking params stripped from URLs
