## User story

As the Scout, I want discovery exposed as MCP tools so that I can run and preview searches with typed inputs and outputs.

## Context

Tools: search.list_profiles, search.preview(profile, limit) (no ledger writes), search.run(profile) (writes DISCOVERED/SCREENED_OUT, returns RunSummary). Long runs return a run_id and are pollable (search.status).

## Acceptance criteria

- [ ] search.run is idempotent per (profile_hash, time bucket)
- [ ] {'RunSummary includes counts': 'fetched, normalized, duplicates, screened_out, new, site_failures'}
