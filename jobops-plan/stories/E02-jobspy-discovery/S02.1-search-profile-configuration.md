## User story

As Doc, I want my searches defined in one validated config file so that what the Scout looks for is explicit and changes are reviewable.

## Context

search_profiles.yaml: name, search_term, google_search_term, locations[], remote_ok, sites[], hours_old, job_type, results_wanted, exclusions (companies, title keywords), min_salary, seniority, enabled. Changes go through Doc approval (S06.3).

## Acceptance criteria

- [ ] Invalid profiles fail validation with field-level messages
- [ ] Profiles hash-versioned; each run records the profile hash used
