## User story

As Doc, I want obvious misfits dropped before any LLM spend so that cost and noise stay low.

## Context

Rules from profile: excluded companies, excluded title keywords, min_salary (only when salary known), seniority floor (title heuristics), location/remote policy, staffing-agency detection list. Result: SCREENED_OUT with reason codes, or passes as DISCOVERED.

## Acceptance criteria

- [ ] Each screened-out job carries ≥ 1 reason code
- [ ] Unknown salary never fails the salary rule
