## User story

As the Scout, I want a run to degrade gracefully when a board blocks us so that one site's failure never costs the whole search.

## Context

Retry with exponential backoff + jitter on 429/5xx; per-site circuit breaker (open after 3 consecutive failures, half-open after cooldown); optional proxy list rotation; per-site results_wanted cap; politeness delay between sites.

## Acceptance criteria

- [ ] A failing site yields a partial result with a SiteFailure record; others succeed
- [ ] Circuit breaker state persists across runs (in ledger metadata)
