## User story

As Doc, I want Approve / Revise / Skip from Telegram, Notion or the Paperclip UI to land identically so that the ledger, Paperclip and Notion always agree.

## Context

Command service is the single entry for doc actions — resolves the Paperclip approval, transitions the ledger (APPROVED / TAILORING via [REVISE] / ARCHIVED with reason 'doc_skip'), updates Notion, confirms in Telegram. On APPROVED, Doc gets an apply checklist (link to posting, PDF, cover letter text to paste). Doc confirms 'applied' → APPLIED. Paperclip UI approvals are picked up by webhook/poll.

## Acceptance criteria

- [ ] All three surfaces produce identical ledger events (except source field)
- [ ] Double-tap / duplicate commands idempotent
