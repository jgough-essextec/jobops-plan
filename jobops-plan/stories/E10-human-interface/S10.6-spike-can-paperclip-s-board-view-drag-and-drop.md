## User story

As the builder, I want to know whether Paperclip's own Board view supports dragging issues between status columns, and how it can be extended, so that we choose between configuring Paperclip (S10.7) and building our own board (S10.8).

## Context

Paperclip's docs describe a Board view on the Issues page with card density, cold-lane mode and column page size, but they describe changing status through a Properties picker and do not mention dragging. They also list a Plugin SDK. Timebox: 1 day on the pinned Paperclip version. Check: drag between status columns on desktop and phone browsers; whether drags respect checkout locks (an agent holding an issue); whether columns can be custom (e.g. by label stage:*) or only status; whether a plugin can add a page or view; which API calls a status change makes.
