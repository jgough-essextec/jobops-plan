## User story

As Doc, I want the pipeline in my Notion database, and simple status changes there to flow back safely, so that Notion stays my tracker.

## Context

Projection — ledger → Notion DB (properties: Company, Role, Grade, Score, Stage, Links, Last update, Next action). Rebuildable. Inbound — Doc sets a 'Doc action' select (Promote, Skip, Mark applied, Revise) → poller converts to ledger commands as actor doc; other edits ignored and reverted with a comment.

## Acceptance criteria

- [ ] Full rebuild yields no diff vs incremental
- [ ] Doc actions applied within one poll (≤ 60s)
