## User story

As Doc, I want my revise comments and skip reasons to make the agents better over time so that I repeat myself less.

## Context

Doc feedback is stored as structured notes (category, text, job context). Weekly, the Manager proposes additions to the Tailor and Critic skills ('house style' section) as an approval request; approved changes are committed to paperclip/skills and re-synced.

## Acceptance criteria

- [ ] No skill changes without approval
- [ ] Each skill change records the feedback ids it came from
