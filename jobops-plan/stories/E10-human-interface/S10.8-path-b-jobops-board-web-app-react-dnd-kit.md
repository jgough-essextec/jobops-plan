## User story

As Doc, I want a drag-and-drop Kanban web app over Paperclip and the ledger so that I get a true parallel board for the agents' work and my pipeline, usable from my phone.

## Context

A small React + TypeScript app (Vite) in services/board_ui, using @dnd-kit/core + @dnd-kit/sortable. dnd-kit is chosen over Pragmatic drag and drop because dnd-kit uses pointer/touch sensors (Doc drives this from a phone) and has a ready sortable preset; Pragmatic, which builds on the browser's native drag API, stays the fallback if performance becomes a problem. Two modes: Pipeline (columns = ledger stages; same board_rules as S10.5; drops call the S10.3 command service as actor doc) and Agent work (columns = Paperclip issue statuses, swimlanes per agent; drops PATCH /api/issues/{id} status via a thin backend that holds the Paperclip board key). Backend: a small FastAPI 'board-api' that reads from the ledger + Paperclip REST, enforces board_rules, and pushes updates by server-sent events. Served only on the tailnet, with a Doc-only session token. If the S10.6 spike found the Plugin SDK can host a page, the app is packaged as a Paperclip plugin page instead of a separate site.

## Acceptance criteria

- [ ] Both modes render from live data and update within 5s of a change made elsewhere (Notion, Telegram, agents)
- [ ] Legal drops take effect; illegal drops snap back with the reason; drops on issues checked out by an agent are refused
- [ ] Works on mobile Safari/Chrome with touch drag; keyboard drag works (accessibility)
- [ ] Never exposes an action that agents can't already be refused (no 'submit', no 'send')
