## User story

As Doc, I want a Kanban board of my job pipeline in Notion, where dragging a card moves the job, so that I can see and steer the whole search at a glance from my phone.

## Context

A Board view on the JobOps Notion database, grouped by Stage. Columns: Discovered, Evaluated, Hold, Shortlisted, Tailoring, In Review, Ready for Doc, Approved, Applied, Interviewing, Offer, Rejected (Archived and Screened-out hidden). Cards show company, role, grade, score, next action, and the age of the item in its stage. The view is set up from code (Notion API) so it can be rebuilt. Dragging changes the Stage property; the poller from S10.1 treats a Stage change as a command from Doc. Board rules (`board_rules.yaml`) derive the legal drag moves from the state machine: only moves where actor=doc is allowed, e.g. Hold→Shortlisted, Ready for Doc→Approved or →Tailoring (revise), Approved→Applied, any→Archived. Illegal drags snap back with a comment explaining why. This module is shared with S10.8.

## Acceptance criteria

- [ ] Board view exists with the columns above, in that order, and can be recreated by `jobops notion setup-board`
- [ ] A legal drag moves the job in the ledger as actor doc within one poll (≤ 60s)
- [ ] An illegal drag is reverted with a comment naming the allowed moves
- [ ] Optional swimlanes: Hold, Escalated and Needs-your-look appear as a filtered 'My queue' board
