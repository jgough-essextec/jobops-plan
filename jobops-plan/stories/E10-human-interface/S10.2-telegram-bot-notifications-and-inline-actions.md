## User story

As Doc, I want Telegram alerts with one-tap actions so that I can run the pipeline from my phone.

## Context

Bot restricted to Doc's chat id. Message types — READY_FOR_DOC card, interview/offer alerts, escalations, daily digest. Inline buttons → signed callback payloads (HMAC, expiry) → command service as actor doc. Commands — /status, /hold, /digest.

## Acceptance criteria

- [ ] Messages from any other chat id ignored and logged
- [ ] Callback payloads tamper-proof and expire after 7 days
